# ClawEh Manual

ClawEh is a self-hosted program that runs one or more personal AI assistants on a computer you control. Each assistant, called an agent, has its own models, tools, files and memory, and you reach it through the WebUI chat, chat apps such as Telegram, Slack and Discord, or paired devices. This manual covers installing ClawEh, connecting it to models, setting up agents and channels, and running it safely.

New to ClawEh? Start with the [Overview](./getting-started/overview.md), then follow the [Quick start](./getting-started/quickstart.md).
